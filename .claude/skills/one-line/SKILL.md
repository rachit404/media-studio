---
name: one-line
description: Answer in exactly one line. Use when the user says "one-line" or "/one-line", or asks for a one-line answer, status or summary.
---

Reply with a single line of plain text: no heading, no list, no code block, no preamble, no follow-up question.
Put the answer first. If the honest answer needs more than one line (a failure, a risk, a decision the user must make), still
use one line and say that more detail is available, for example "Failed: 2 tests, ask for details."
Do not change files or run commands just to produce the line, unless the user's request itself needs them.
