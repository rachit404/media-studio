---
name: explain-in-short
description: Explain a topic, change, error or piece of code briefly in plain words. Use when the user says "explain-in-short" or "/explain-in-short", or asks for a short explanation.
---

Explain the topic in at most five short bullet points (or three sentences), in plain words a non-expert can follow.
Order: what it is, what it does here, why it matters. Name a file only when it helps the reader find it.
No code unless the user asks for it; no history; no alternatives unless they change the answer.
Do not change files or run commands just to explain, except to read what is needed to be accurate.
