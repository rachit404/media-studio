# Proposed repository structure

- **Status:** Proposed for owner approval (2026-11-17). Created in M0 only after approval.
- **Related:** [ADR-0010](../adr/0010-tooling-and-repo-structure.md), [system architecture](../architecture/system-architecture.md)

## Tree
```
media-studio/
├─ apps/
│  └─ web/                    # the application (composition root)
│     ├─ src/
│     │  ├─ app/              # providers, routing, shell layout
│     │  ├─ workspaces/       # home/, image/, video/ (screens + panels)
│     │  ├─ features/         # export dialog, settings, recovery, relink
│     │  ├─ workers/          # worker entry points (render, decode, export, storage, analysis)
│     │  └─ styles/theme.css  # the single design-token file
│     ├─ public/              # manifest, icons, fonts (open licences)
│     └─ index.html
├─ packages/
│  ├─ core/                   # document model, schemas, commands, history, journal, time maths, errors
│  ├─ capabilities/           # runtime probes and report
│  ├─ media-io/               # MediaEngine: probe, decode, encode, mux (WebCodecs + Mediabunny)
│  ├─ render/                 # Renderer interface, Pixi/WebGL2 impl, blend and effect shaders
│  ├─ storage/                # FileAccess, ProjectStore, OPFS/FSA, journal I/O, archive
│  ├─ engine-image/           # layer ops, tools, selections, brush, image export
│  ├─ engine-video/           # timeline ops, playback, decode scheduler, caches, audio, export orchestration
│  ├─ ui/                     # design-system components (React Aria + Tailwind tokens)
│  └─ testing/                # fixtures builders, golden-image helpers, test utilities (dev only)
├─ e2e/                       # Playwright tests
├─ fixtures/                  # tiny generated/CC0 media only (large fixtures are generated by scripts)
├─ scripts/                   # fixture generation, licence check, size budget, probe runner
├─ docs/                      # product, architecture, ADRs, research, engineering, ui
├─ .github/                   # workflows, PR/issue templates, CODEOWNERS
├─ README.md  LICENSE  CONTRIBUTING.md  SECURITY.md  CODE_OF_CONDUCT.md  CHANGELOG.md
└─ pnpm-workspace.yaml  package.json  tsconfig.base.json  eslint.config.js  .editorconfig  .gitignore
```
Package scope: `@media-studio/<name>`. The spike code is **not** carried into `main`; it is kept on a git tag (`spikes-2026-11`) and its results live in `docs/research/`.

## Allowed dependencies (enforced by tooling)
| Package | May import | Must not import |
|---|---|---|
| `core` | nothing from the workspace | any browser API, React, other packages |
| `capabilities` | `core` (types, errors) | engines, UI |
| `media-io` | `core`, `capabilities` | `render`, `storage`, engines, UI |
| `render` | `core`, `capabilities` | `media-io`, `storage`, engines, UI |
| `storage` | `core`, `capabilities` | `media-io`, `render`, engines, UI |
| `engine-image` | `core`, `render`, `storage` | `engine-video`, `media-io`, UI |
| `engine-video` | `core`, `media-io`, `render`, `storage` | `engine-image`, UI |
| `ui` | React, `core` (types) | engines, adapters |
| `apps/web` | everything | (it is the composition root) |
Browser-only APIs (WebCodecs, OPFS, FSA, WebGL, Web Audio) appear only in `media-io`, `render`, `storage`, `capabilities` and `apps/web` worker entry points.

## Conventions
- **Branches:** `main` only protected; short-lived `feat/…`, `fix/…`, `docs/…` branches; squash-merge with a conventional-commit title (`feat(image): add overlay blend shader`).
- **Commits/PRs:** conventional commits; PR template requires linked requirement IDs, tests, docs and licence notes for new dependencies.
- **Never committed:** secrets, media, caches, build output, OS/editor files, spike artefacts. Enforced by `.gitignore` and secret scanning.
- **Documentation:** one source of truth per topic; architecture changes update the relevant doc and add or amend an ADR; [STATUS.md](../STATUS.md) updated at the end of each milestone.
- **Naming:** files `kebab-case`; types `PascalCase`; no default exports in packages; public API only via each package's `index.ts`.
- **File size guideline:** components and modules stay small (aim under ~300 lines); split by responsibility, not by layer count.
